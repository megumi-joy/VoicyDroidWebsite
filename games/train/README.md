# 🚃 Дикие Поезда

Коллекция концепт-артов и сценариев визуальной новеллы про дикие электрички.

## Путешествия

### Поездка 1: Из Леса в Альмерию (Фантазия)
Дикая Электричка — живой механизм, прокладывающий путь через заросшие леса и горы. Маршрут ведёт из **Ржавого Депо** через грибные подземелья, затопленные вокзалы и станции на деревьях к **Приморскому Терминалу** у океана.

**Станции:** Депо → Споры → Затопленный Вокзал → Крона → Виадук → Альмерия

### Поездка 2: Альмерия → Мадрид-Чамартин (Испания)
Реальный маршрут Renfe Cercanías. Ржавая электричка-серканиас с граффити — якорь нормальности в сюрреалистичном, заросшем мире. Герой едет от океана до единственной работающей станции.

**Станции:** Альмерия → Кордоба-Мескита → Севилья → Деспеньяперрос → Кастилья → Мадрид-Чамартин

### Поездка 3: Мадрид → Барселона (Левант)
Из Чамартина — на юго-восток через **Хаэн** (оливки), **Гранаду** (Альгамбра), **Табернас** (единственная пустыня Европы), вдоль побережья через **Картахену**, **Аликанте**, **Валенсию**, в **Сарагосу** и до **Барселоны**. 19 станций, от рассвета над рисовыми полями до заката в Estació de França.

**Станции:** Мадрид → Хаэн → Гранада → Табернас → Мурсия → Картахена → Эльче → Аликанте → Бенидорм → Ночная → Альбуфера → Валенсия → Сагунто → Кастельон → Теруэль → Сарагоса → Монегрос → Таррагона → Барселона

### Побочная Линия: Дикий Баклажан
Второй поезд — **Nightshade Express**. Гигантский баклажан, сросшийся с локомотивом, прибывает на заброшенную станцию Gare de l'Aubergine.
